# Changelog

## Version 3.0.0 — 29 July 2026

- Fixed ticket prices showing as `$0` when the report stores the ticket at the start of the first description line.
- Automatically repairs previously saved `$0` ticket values when the dashboard opens.
- Removes the recovered price prefix from the displayed item description.
- Replaced the top estimated net sale return card with total ticket price.
- Total ticket price now follows the current search, metal and priority filters.

## Version 2.0.0 — 28 July 2026

- Added a fixed 15% New Zealand GST deduction.
- Added an editable selling fee, defaulting to 15%.
- Added estimated net sale return totals and per-item values.
- Changed melt-risk percentages and warning colours to compare melt value with net sale return.
- Changed melt opportunities to identify items whose melt value exceeds net sale return.
- Changed dollar differences to show melt advantage or net sale advantage.

## Version 1.0.0 — 28 July 2026

- Created the Jewellery Melt Decision Dashboard.
- Added three-store filtering and store-specific report uploads.
- Added Cash Converters burgundy and yellow visual theme.
- Added stocktake report section detection and multi-line description parsing.
- Added gold and sterling silver refinery calculations.
- Added daily NZD metal price refresh and manual scenario prices.
- Added editable priority thresholds.
- Added stock search, filters, sorting and Needs Review workflow.
- Added responsive desktop and mobile layouts.
